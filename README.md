This repository contains the code used in "Angiocrine IGF-1 Regulates Epidermal Stratification" by Bishop et al.

To investigate a potential role for endothelial cells in epidermal development, we analyzed a publicly available single-cell transcriptomic dataset (Jacob et al., 2023).

Inferred signalling interactions were investigated using CellChat.

Further information can be found in the manuscript Bishop et al., 2026.
